Pass 2 — H33 claim, byte readback, and source boundaries

The premise that the GEMSDOE32 site proves the named H33 TIFF earned 0.2778 is not supported by the pinned page retrieved from GitHub. That owner-maintained page describes H33-2-B2 as pruning dots at catalogue distance <= 2 px from a 0.2708 OWNER-REPORT base value (not authenticated as a score), leaving 37,654 dots (RASTER-MEASUREMENT). It reports a live-mirror OWNER-MODEL PROJECTION of 0.2747 and expressly says “NO ORGANISER SCORE EXISTS for this or any artifact in this repository.” This is an owner-site statement, not an organizer receipt. The exact retrieved source, commit, bytes and SHA-256 are in the source receipt.

An independent readback of the pinned H33 mirror matched SHA-256 c55bafc470054e8271dcb89347a17e07fefe50de6af6e6ba6c4b169ef7ab6fa9, the reference EPSG:32611 grid, and a single float32 band with values {0,1}. It measured 37,654 positive pixels, 0 on the known catalogue, and minimum catalogue distance 2.236 pixels. These are RASTER-READBACK MEASUREMENTS, not a score or a uniqueness pass. The retained earlier pixel-forensics receipt says the H33 family version removed 6,436 near-catalogue dots from a 44,090-dot predecessor without additions; that predecessor comparison is historical forensics, not a freshly reproduced score attribution.

The plausible metric mechanism is conditional, not causal proof. The repository's pinned metric transcription uses a triangular distance kernel with a 300 m radius on the 100 m grid and DTI = TP / (TP + 0.2 FP + 0.8 FN): TP is the sum, over hidden-truth cells, of the best predicted kernel-weighted credit; FP sums predicted mass not supported by nearby truth; FN = |G| - TP. The max in TP makes extra dots around already-covered truth progressively redundant, while a dot can still incur false-positive mass away from hidden truth. If two artifacts were actually evaluated on identical hidden labels, pruning can improve DTI when it removes predicted mass that does not cover hidden truth while retaining enough truth coverage. It can also lower DTI if removed dots were the only nearby coverage for withheld faults. A distance-to-known-catalogue pruning rule does not, by itself, reveal which case occurred. Moreover, the exact marginal rule for adding one dot is dT > alpha*DTI*(dT + 1 - k); the shortcut k > alpha*DTI only applies when its marginal truth credit equals its own kernel credit (dT == k). Neither algebra nor raster geometry identifies an organizer score.

Consequently, 0.2778 is OWNER-REPORT, not ORGANIZER-CONFIRMED for these bytes. The pinned page's 0.2747 is an OWNER-MODEL PROJECTION, not a score. The prompt's purported current leader values 0.3195 and 0.4413 conflict; neither was freshly retrieved from the official leaderboard or tied to a submission receipt here. This review does not state which is current and makes no claim that H33 was the highest verified score. Fault-recovery DTI is also only the competition's fault-detection proxy; it is not direct geothermal-vent detection or proof of an exploitable resource.
