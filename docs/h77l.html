Local structure-tensor scarp normal, positive 300 m ThK flank contrast minus 1.25x zero-lag gradient, weighted by lidar step and coherence; raw inputs only, no previous submission reused. The 1–255 ThK uint8 channel is percentile-quantized rank intensity; this experiment does not measure chemical concentrations, permeability, geothermal fluids or vent positions. No existing submission prediction is an input. A component-complete four-quadrant hide-and-recover with an 80-pixel training buffer uses only the visible mapped faults to mask each fold; hidden components cannot become catalogue features.
