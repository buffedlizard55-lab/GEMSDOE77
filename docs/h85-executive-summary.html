❌ Common Errors & Fixes

Error: "Predicted values must be in range [0, 1]"

ERROR: Predicted values must be in range [0, 1]

Cause: Your TIF contains values outside [0, 1], or NaN.

Fix:

  1. Run format validation: python vendor/gems57/validate.py your_file.tif
  2. Check for NaN: python -c "import numpy as np, rasterio; print(np.any(np.isnan(rasterio.open('your_file.tif').read(1))))"
  3. Check range: python -c "import numpy as np, rasterio; data=rasterio.open('your_file.tif').read(1); print(f'min={data.min()}, max={data.max()}')"
  4. Ensure binary: data = (data > 0).astype(np.float32)

Error: "File does not match submission format"

Cause: Wrong CRS, dimensions, or transform.

Fix:

  1. Verify CRS: Must be EPSG:32611
  2. Verify dimensions: Must be 3730×3292 (width×height)
  3. Verify transform: Must be (100, 0, 243350, 0, -100, 4508550)
  4. Use sample_submission.tif as template

Error: "File contains NaN values"

Cause: Your processing created NaN values.

Fix:

  1. Replace NaN with 0: data = np.nan_to_num(data, nan=0.0)
  2. Ensure all operations preserve finite values
  3. Validate with: assert not np.any(np.isnan(data))

Error: Policy I17 Duplicate

Cause: Your submission overlaps >70% with an existing submission.

Fix:

  1. Run uniqueness check: python scripts/h85_uniqueness.py
  2. If overlap > 0.70: Adjust your method to be more distinct
  3. Check against: ab0a0a62 (dense witness covering 100% of footprint)
  4. Note: This currently blocks ALL non-empty submissions in this repository
