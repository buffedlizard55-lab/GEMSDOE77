How to submit a promoted file (only when the selector says so)

  1. On the repository start page, confirm the file's row says OK to submit and the selector chip says approved. (No current file does; every file today says Not OK to submit.)
  2. Download the -zeros.tif file (or its one-TIFF .zip) from its lane page. Do not use a -nan.tif twin — those are diagnostics.
  3. Check the sha256 on the lane page matches your download, and note the exact submission name and ≤140-character Note text given there.
  4. Go to the DrivenData competition's New submission page (competition home → Submissions → New submission). The form accepts a single-band GeoTIFF (.tif) or a .zip containing a single GeoTIFF, matching the submission format's CRS, shape and geotransform.
  5. Choose the downloaded file under File to submit. Paste the Note text into the Note field (a short comment to tell submissions apart later). Keep the downloaded file name as-is so it matches the recorded name.
  6. Click Create submission. If the portal returns "Predicted values must be in range [0, 1]", stop: that file is not the all-finite -zeros.tif (this repo's writer guarantees finite values in [0,1], nodata=None, and re-validates on disk; report the file name and hash instead of trying another variant).
  7. Record the organizer score from the submission page/leaderboard as ORGANIZER-CONFIRMED with its receipt. A local HOLDOUT-DTI or a projection is never a score.
