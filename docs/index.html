Why the H33 file might have achieved the owner's reported 0.2778

Direct raster measurement, not an authenticated causal leaderboard attribution: the archived H33 file has 37,654 positive pixels on the H19-5 backbone. It is exactly the earlier 44,090-pixel dotted raster with the 6,436 dots at or within 200 m of the known catalogue removed; no new fault pixels were added (pixel-forensics receipt). The official 300 m triangular DTI kernel rewards coverage but penalizes redundant prediction mass. Sparse dots and near-catalogue pruning are a plausible way to cut false positives while retaining nearby unmapped-fault coverage. This explains the *mechanism*, not proof that the specific file received that score or that another submission will beat it. Long-form analysis →
