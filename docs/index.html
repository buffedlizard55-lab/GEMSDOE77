Why GEMSDOE32 scored 0.2778 — and how H77E advances beyond it

Under the official metric (problem description: α = 0.2 false-positive weight, β = 0.8 false-negative weight, 300 m = 3 px triangular tolerance kernel), smooth continuous probability rasters suffer severe denominator inflation across 5.17M background cells (0.0107–0.0343), while wide multi-pixel ribbons pay 3×–7× redundant false-positive penalties for pixels already covered by an adjacent 1.0 dot (0.1461). GEMSDOE32 (H33) reached 0.2778 by placing 37,654 isolated binary 1.0 dots spaced 3 px apart off known mapped faults along the H19-5 structural lineament set — capturing up to 2.33 fault-equivalent pixels of numerator credit per dot for only 0.2 denominator cost.
